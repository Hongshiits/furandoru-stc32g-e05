## 依赖保护

- `mechanical/solidworks/n30-zfcar/native/` 内的 SolidWorks 装配体和零件保持原始文件名并置于同一目录，避免破坏装配引用。
- MUX_EMF 只保留 Keil 工程、配置和源码；`Objects/`、`Listings/` 及用户状态文件不发布。
- 原始 `.eprj/.eprj2` 是含本地用户凭据的 SQLite 数据库，全部排除；可发布工程仅使用已审计的 `.epro/.epro2` 导出。
- 完全相同的副本通常不重复存储；清单仍记录每个原路径、修改时间和哈希。N30 主板支架 DXF 是唯一跨上下文例外，用于同时保持硬件接口入口与完整第三方快照。
- DXF 的 `$LASTSAVEDBY` 和绝对源文件路径字段已从发布副本清除，几何实体保持不变。
- 147.9 MB 的扫描参考 PNG 不属于 3D 工程，且超过 GitHub 普通 Git 单文件限制，因此仅在清单留档。
